# Luminé Glow — Cosmetic E-Commerce

A beginner-friendly cosmetic e-commerce website built with:
- HTML5
- CSS3
- Vanilla JavaScript
- PHP 8+
- MySQL

No frameworks or libraries are required.

## Setup

1. Copy the `lumine_glow` folder into your XAMPP `htdocs` folder.
2. Start Apache and MySQL.
3. Open phpMyAdmin.
4. Import `database/lumine_glow.sql`.
5. Check `includes/db.php` and update the MySQL username/password if needed.
6. Open:
   `http://localhost/lumine_glow/`

## Included
- Home page
- Product catalogue
- Category filtering
- Product details
- Session-based shopping cart
- Checkout form
- Order storage in MySQL
- Basic login/register
- Beauty quiz
- Responsive design
